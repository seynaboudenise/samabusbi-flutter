# SAMA BUS Flutter App

Prototype Flutter de SAMA BUS.

## Parcours

Splash Screen -> Login -> Dashboard

## Installation

```powershell
flutter pub get
flutter run -d chrome
```

Pour Android :

```powershell
flutter devices
flutter run -d emulator-5554
```

## Important

La connexion est actuellement une simulation. Les données de bus et la carte sont également des données de démonstration.

Les prochaines étapes peuvent être :
- authentification réelle ;
- Google Maps ;
- GPS ;
- positions des bus en temps réel ;
- API backend ;
- tickets ;
- profil utilisateur.
